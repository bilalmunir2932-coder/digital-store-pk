# DIGITAL STORE website starter

A responsive, animated front-end website for Digital Store.

## Run locally
Open `index.html` in a modern browser. For a more reliable local preview, run a static server from this folder, e.g. `python -m http.server 8000`, then visit `http://localhost:8000`.

## Included
- Responsive premium dark theme with purple/blue glow effects
- Animated hero section featuring the supplied owner photo
- Category-first home view: click a platform/category to open only its services
- Service category tabs and live search
- Service cards with price and package labels, including Website Design & Development with custom quote
- WhatsApp order links prefilled with service, price and package
- Contact section with WhatsApp 03198682932 and email bilalmunir2932@gmail.com
- Mobile navigation and reduced-motion accessibility support

## Before publishing
1. Verify every catalog item and price against the original promotional images. This starter includes prices transcribed from the conversation and flags the catalog as needing final verification.
2. Confirm whether the item currently named `SHARE` should use a different exact spelling/name.
3. Confirm the final service list, delivery terms, and any conditions for each package.
4. Add privacy policy, terms, support/contact details, and any genuine login/account backend only if needed.
5. Deploy to a hosting provider and connect a domain if desired.

## Important
This is a front-end starter, not a live deployed website. No payment gateway or real customer login is implemented. Orders open WhatsApp for the customer to review and send manually.
